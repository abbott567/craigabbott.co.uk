# craigabbott.co.uk

This is a public facing repo to report issues with [craigabbott.co.uk](https://www.craigabbott.co.uk).

There's no code here. The site itself is built with Eleventy and lives in a private repo, but this repo exists so people have somewhere to tell me when something on the site is broken, wrong, or difficult to use.

## What to report

Anything, really, but especially:

- **Accessibility issues**: For example, poor colour contrast, keyboard issues, unhelpful headings, and content not reflowing properly
- **Usability issues**: Anything that stops you using the site, including with assistive technologies, for example screen readers, magnification or voice control
- **Bugs**: Things which don't work as expected, for example images not loading or broken links
- **Content issues:** Typos, broken code examples, factual errors, out-of-date advice, or anything you feel I could have worded better
- **Suggestions**: Something you'd find useful, but isn't there yet
- **Feedback**: General feedback, good or bad!

Small things are worth reporting. If it bothered you enough to notice, it's worth raising an issue.

## How to report an issue

> [!NOTE]
> None of this is mandatory. A one-line issue that says "the code blocks are unreadable on my phone" is still useful.

1. Check existing issues in case it's already been raised
2. Open a new issue
3. Include as much of the following as you can:
   - The URL of the page
   - What you expected to happen, and what actually happened
   - Your browser and operating system
   - Your assistive technology and version, if you're using any
   - A screenshot or screen recording, if it helps

### If you'd rather not use GitHub

Not everyone has a GitHub account, and the interface isn't equally usable for everyone. There are [alternative ways to contact me](https://www.craigabbott.co.uk/contact-me/).

### Security issues

Please don't open a public issue for anything security related. [Contact me](https://www.craigabbott.co.uk/contact-me/) directly and I'll deal with it.

## What happens next

This is a personal site I maintain in my spare time, so I can't promise a timescale. But, I promise you, I do read everything! Security and accessibility issues will go to the front of the queue.

## A note on tone

Please be kind. To me, and to each other. I reserve the right to close abusive issues without discussion.
